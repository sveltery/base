### Root

Groups all parts of the navigation menu. Renders a `<nav>` element at the root, or `<div>` element when nested.

**Root Props:**

| Prop                 | Type                                                                                                            | Default        | Description                                                                                                                                                                                                                                   |
| :------------------- | :-------------------------------------------------------------------------------------------------------------- | :------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| defaultValue         | `Value \| null`                                                                                                 | `null`         | The uncontrolled value of the item that should be initially selected.&#xA;&#xA;To render a controlled navigation menu, use `bind:value` instead.                                                                                              |
| value                | `Value \| null`                                                                                                 | `null`         | The value of the navigation menu item that should be currently open. When non-nullish, the menu will be open. When nullish, the menu will be closed.&#xA;&#xA;To render an uncontrolled navigation menu, use the `defaultValue` prop instead. |
| onValueChange        | `(value: Value \| null, eventDetails: NavigationMenuChangeEventDetails) => void`                                | -              | Callback fired when the value changes.                                                                                                                                                                                                        |
| onOpenChangeComplete | `(open: boolean) => void`                                                                                       | -              | Event handler called after any animations complete when the navigation menu is closed.                                                                                                                                                        |
| delay                | `number`                                                                                                        | `50`           | How long to wait before opening the navigation popup. | closeDelay           | `number`                                                                                                        | `50`           | How long to wait before closing the navigation popup.
