## API Reference

### Textarea

A native textarea that works with [Field](https://base.sveltery.dev/components/field) the way Input does. Renders a `<textarea>` element. Sveltery addition, with no Base UI counterpart. It declares `type?: never`, so a remote form spread of another input kind is a type error.

| :----------- | :----------------------------------------------------------------------------------------------- | :------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| defaultValue | `string \| null`                                                                                 | -       | The value an empty `value` starts from, and the value a form reset restores.                                                                                                                                                            |
| value        | `string \| null`                                                                                 | -       | The value of the textarea.                                                                                                                                                                                                              |
| render       | `Snippet<[props: HTMLTextareaAttributes, state: TextareaState, children: Snippet \| undefined]>` | -       | Allows you to replace the component's HTML element with a different tag, or compose it with another component.
