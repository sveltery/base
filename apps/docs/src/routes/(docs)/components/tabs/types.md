## API Reference

### Root

Groups the tabs and the corresponding panels. Renders a `<div>` element.

**Root Props:**

| Prop          | Type                                                                                                     | Default        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| :------------ | :------------------------------------------------------------------------------------------------------- | :------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| value         | `TabsValue \| null`                                                                                      | `0`            | The value of the currently active `Tab`. When the value is `null`, no Tab will be active.&#xA;&#xA;To render uncontrolled tabs, pass `value` without `bind:`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| onValueChange | `(value: TabsValue \| null, eventDetails: TabsRootChangeEventDetails) => void`                           | -              | Callback invoked when new value is being set.&#xA;&#xA;The event `reason` is `'none'` for user-initiated changes, such as a click or keyboard navigation; `'initial'` for the first automatic selection or fallback in uncontrolled roots when `value` is omitted or `undefined`, including when the implicit initial value is disabled or missing; `'disabled'` for automatic fallback when the selected tab becomes disabled in uncontrolled roots; or `'missing'` for automatic fallback when the selected tab is removed, or when an explicit initial `value` never matches a mounted tab in uncontrolled roots.&#xA;&#xA;For automatic changes, the selected value can be `null` when no enabled Tab is available as a fallback.&#xA;&#xA;Automatic changes cannot be canceled; calling `eventDetails.cancel()` for `'initial'`, `'disabled'`, or `'missing'` has no effect. |
| orientation   | `TabsOrientation`                                                                                        | `'horizontal'` | The component orientation (layout flow direction).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| render        | `Snippet<[props: HTMLAttributes<HTMLDivElement>, state: TabsRootState, children: Snippet \| undefined]>` | -              | Allows you to replace the component's HTML element with a different tag, or compose it with another component. Accepts a snippet that receives the props to spread onto the element, the component's state, and the children to render.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
