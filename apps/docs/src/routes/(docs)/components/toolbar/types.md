## API Reference

### Root

A container for grouping a set of controls, such as buttons, toggle groups, or menus. Renders a `<div>` element.

**Root Props:**

| Prop        | Type                                                                                                        | Default        | Description                                                                                                                                                                                                                             |
| :---------- | :---------------------------------------------------------------------------------------------------------- | :------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| loopFocus   | `boolean`                                                                                                   | `true`         | If `true`, using keyboard navigation will wrap focus to the other end of the toolbar once the end is reached.                                                                                                                           |
| disabled    | `boolean \| null`                                                                                           | `false`        | -                                                                                                                                                                                                                                       |
| orientation | `ToolbarOrientation`                                                                                        | `'horizontal'` | The orientation of the toolbar.                                                                                                                                                                                                         |
| render      | `Snippet<[props: HTMLAttributes<HTMLDivElement>, state: ToolbarRootState, children: Snippet \| undefined]>` | -              | Allows you to replace the component's HTML element with a different tag, or compose it with another component. Accepts a snippet that receives the props to spread onto the element, the component's state, and the children to render. |

**Root Data Attributes:**

| Attribute        | Type                         | Description                               |
| :--------------- | :--------------------------- | :---------------------------------------- |
| data-orientation | `'horizontal' \| 'vertical'` | Indicates the orientation of the toolbar. |
| data-disabled    | -                            | Present when the toolbar is disabled.     |

### ToolbarButtonHostProps

Props passed to a `render` snippet. Spread them onto the host element. Handlers are typed for a generic element so the same object spreads onto a `<button>`, `<span>`, or `<a>`. `disabled` lets a rendered part, such as a Switch or a Menu.Trigger, disable itself. A focusable disabled native button still ends without the `disabled` attribute.

```typescript
type ToolbarButtonHostProps = HTMLAttributes<HTMLElement> & { disabled?: boolean };
```
