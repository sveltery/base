## API Reference

### Toggle

A two-state button that can be on or off. Renders a `<button>` element.

**Toggle Props:**

| Prop            | Type                                                                                    | Default | Description                                                                                                                                                                                                                             |
| :-------------- | :-------------------------------------------------------------------------------------- | :------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| value           | `string`                                                                                | -       | A unique string that identifies the toggle when used inside a toggle group.                                                                                                                                                             |
| pressed         | `boolean`                                                                               | `false` | Whether the toggle button is currently pressed.&#xA;&#xA;To render an uncontrolled toggle, pass `pressed` without `bind:`.                                                                                                              |
| onPressedChange | `(pressed: boolean, eventDetails: ToggleChangeEventDetails) => void`                    | -       | Callback fired when the pressed state is changed.                                                                                                                                                                                       |
| onclick         | `MouseEventHandler<HTMLButtonElement> \| null`                                          | -       | Runs before the Toggle's handler. Call `event.preventDefault()` to skip it.                                                                                                                                                             |
| nativeButton    | `boolean`                                                                               | `true`  | Whether the component renders a native `<button>` element when replacing it via the `render` prop. Set to `false` if the rendered element is not a button (for example, `<div>`).                                                       |
| disabled        | `boolean \| null`                                                                       | `false` | Whether the component should ignore user interaction.                                                                                                                                                                                   |
| render          | `Snippet<[props: ToggleHostProps, state: ToggleState, children: Snippet \| undefined]>` | -       | Allows you to replace the component's HTML element with a different tag, or compose it with another component. Accepts a snippet that receives the props to spread onto the element, the component's state, and the children to render. |

**Toggle Data Attributes:**

| Attribute     | Type | Description                                 |
| :------------ | :--- | :------------------------------------------ |
| data-pressed  | -    | Present when the toggle button is pressed.  |
| data-disabled | -    | Present when the toggle button is disabled. |
