## API Reference

### Root

Groups all parts of the field. Renders a `<div>` element.

**Root Props:**

| Prop                   | Type                                                                                                   | Default      | Description                                                                                                                                                                                                                                                                                                                                                                        |
| :--------------------- | :----------------------------------------------------------------------------------------------------- | :----------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| name                   | `string \| null`                                                                                       | -            | Identifies the field when a form is submitted. Takes precedence over the `name` prop on the `<Field.Control>` component.                                                                                                                                                                                                                                                           |
| dirty                  | `boolean`                                                                                              | -            | Whether the field's value has been changed from its initial value. Useful when the field state is controlled by an external library.                                                                                                                                                                                                                                               |
| field                  | `F`                                                                                                    | -            | A field of the Form's source, such as `remote.fields.email`. The Field shows its issues, and Field.Control takes its encoded name and value.                                                                                                                                                                                                                                       |
| touched                | `boolean`                                                                                              | -            | Whether the field has been touched. Useful when the field state is controlled by an external library.                                                                                                                                                                                                                                                                              |
| type                   | `ControlType<F>`                                                                                       | -            | -                                                                                                                                                                                                                                                                                                                                                                                  |
| disabled               | `boolean \| null`                                                                                      | `false`      | Whether the component should ignore user interaction. Takes precedence over the `disabled` prop on the `<Field.Control>` component.                                                                                                                                                                                                                                                |
| invalid                | `boolean`                                                                                              | -            | Whether the field is invalid. Useful when the field state is controlled by an external library.                                                                                                                                                                                                                                                                                    |
| validate               | `FieldValidate`                                                                                        | -            | A function for custom validation. Return a string or an array of strings with the error message(s) if the value is invalid. Returning nothing, `null`, an empty string, or an empty array means the value is valid. Asynchronous functions are supported, but they do not prevent form submission when using `validationMode="onSubmit"`.                                          |
| validationMode         | `FormValidationMode`                                                                                   | `'onSubmit'` | Determines when the field should be validated. This takes precedence over the `validationMode` prop on `<Form>`.&#xA;&#xA;- `onSubmit`: triggers validation when the form is submitted, and re-validates on change after submission.&#xA;- `onBlur`: triggers validation when the control loses focus.&#xA;- `onChange`: triggers validation on every change to the control value. |
| validationDebounceTime | `number`                                                                                               | `0`          | How long to wait between `validate` callbacks if `validationMode="onChange"` is used. Specified in milliseconds.                                                                                                                                                                                                                                                                   |
| render                 | `Snippet<[props: HTMLAttributes<HTMLElement>, state: FieldRootState, children: Snippet \| undefined]>` | -            | Allows you to replace the component's HTML element with a different tag, or compose it with another component. Accepts a snippet that receives the props to spread onto the element, the component's state, and the children to render.                                                                                                                                            |

### Control

The form control to label and validate. Renders an `<input>` element.

You can omit this part and use any Base UI input component instead. For example, [Input](https://base.sveltery.dev/components/input), [Checkbox](https://base.sveltery.dev/components/checkbox), or [Select](https://base.sveltery.dev/components/select), among others, will work with Field out of the box.
