## API Reference

### CSPProvider

Provides a default Content Security Policy (CSP) configuration for Base UI components that require inline `<style>` or `<script>` tags.

**CSPProvider Props:**

| Prop                 | Type                   | Default | Description                                                                                                                                                                      |
| :------------------- | :--------------------- | :------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| disableStyleElements | `boolean \| undefined` | `false` | Whether inline `<style>` elements created by Base UI components should not be rendered. Instead, components must specify the CSS styles via custom class names or other methods. |
| nonce                | `string \| undefined`  | -       | The nonce value to apply to inline `<style>` and `<script>` tags.                                                                                                                |
