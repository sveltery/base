## API Reference

### Root

Holds the slots and the input that types into them. Rest props go to the input. Renders a `<div>` element.

**Root Props:**

| Prop                        | Type                                  | Default            | Description                                                                                                       |
| :-------------------------- | :------------------------------------ | :----------------- | :---------------------------------------------------------------------------------------------------------------- |
| defaultValue                | `string`                              | `''`               | The code an empty `value` starts from.                                                                            |
| value                       | `string`                              | -                  | The code.                                                                                                         |
| containerClass              | `ClassValue \| null`                  | -                  | Class for the container that holds the slots and the input.                                                       |
| maxlength                   | `number`                              | -                  | The number of slots.                                                                                              |
| noScriptCSSFallback         | `string \| null`                      | -                  | CSS that shows the plain input when JavaScript is off. `null` leaves it out.                                      |
| onComplete                  | `(value: string) => void`             | -                  | Called with the value when the last slot fills.                                                                   |
| pasteTransformer            | `(pasted: string) => string`          | -                  | Rewrites pasted text before it is inserted.                                                                       |
| pattern                     | `string \| RegExp`                    | -                  | Every value must match it, for example `REGEXP_ONLY_DIGITS`. Input that doesn't match is dropped.                 |
| placeholder                 | `string`                              | -                  | Characters shown in the empty slots, one per slot, through `placeholderChar`.                                     |
| pushPasswordManagerStrategy | `'increase-width' \| 'none'`          | `'increase-width'` | Widens the input so a password manager's badge sits outside the slots.                                            |
| textAlign                   | `'left' \| 'center' \| 'right'`       | `'left'`           | The text alignment of the input.                                                                                  |
| render                      | `Snippet<[state: InputOTPRootState]>` | -                  | Renders the slots from the state. Without it, `children` renders and reads the state with `getInputOTPContext()`. |

**Root Data Attributes:**

| Attribute                        | Type     | Description                                                    |
| :------------------------------- | :------- | :------------------------------------------------------------- |
| data-input-otp                   | -        | Present on the input.                                          |
| data-input-otp-container         | -        | Present on the container that holds the slots and the input.   |
| data-input-otp-mse               | `number` | The end of the selection the slots mirror, set on the input.   |
| data-input-otp-mss               | `number` | The start of the selection the slots mirror, set on the input. |
| data-input-otp-placeholder-shown | -        | Present on the input while the value is empty.                 |

**Root CSS Variables:**

| Variable        | Type     | Description                                    |
| :-------------- | :------- | :--------------------------------------------- |
| `--root-height` | `number` | The height of the input, set on the container. |
