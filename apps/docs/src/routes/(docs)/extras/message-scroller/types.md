## API Reference

### Root

The frame around the viewport. It mirrors the viewport's scroll-state attributes. Renders a `<div>` element.

**Root Data Attributes:**

| Attribute           | Type                              | Description                                                                                                                                            |
| :------------------ | :-------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------- |
| data-autoscrolling  | -                                 | Present while a programmatic scroll to the end runs.                                                                                                   |
| data-pending-scroll | -                                 | Present until the `'end'` or `'last-anchor'` opening position is applied. Hide the viewport with `visibility: hidden` while it is set.                 |
| data-scrollable     | `'start' \| 'end' \| 'start end'` | The edges the viewport can scroll toward: `start`, `end` or `start end`. Absent when the content fits. Match one edge with `[data-scrollable~="end"]`. |

### Provider

Owns the scroll state and the behavior props, and provides them to the parts and `getMessageScroller()`. Doesn't render its own HTML element.

**Provider Props:**

| Prop                   | Type                                   | Default | Description                                                                |
| :--------------------- | :------------------------------------- | :------ | :------------------------------------------------------------------------- |
| autoScroll             | `boolean`                              | `false` | Follow new content at the bottom while the viewport is already at the end. |
| defaultScrollPosition  | `MessageScrollerDefaultScrollPosition` | `'end'` | Opening position on the first non-empty render, applied once.              |
| scrollEdgeThreshold    | `number`                               | `8`     | Distance from an edge that still counts as at the start or end.            |
| scrollMargin           | `number`                               | `0`     | Default margin on the aligned edge for commands and visibility.            |
| scrollPreviousItemPeek | `number`                               | `64`    | Extra top margin for a newly anchored row, added to `scrollMargin`.        |

### Item

One transcript row: a message, marker, typing row, separator or load-more row. Renders a `<div>` element.

**Item Props:**

| Prop         | Type      | Default | Description                                                                      |
| :----------- | :-------- | :------ | :------------------------------------------------------------------------------- |
| messageId    | `string`  | -       | Stable row id for `scrollToMessage`, visibility and prepend preservation.        |
| scrollAnchor | `boolean` | `false` | Marks a turn boundary that newly appended anchors and `last-anchor` restore use. |

**Item Data Attributes:**

| Attribute          | Type                | Description                          |
| :----------------- | :------------------ | :----------------------------------- |
| data-message-id    | -                   | The item's `messageId`.              |
| data-scroll-anchor | `'true' \| 'false'` | Whether the item is a turn boundary. |

### Button

Scrolls to the start or end of the transcript. It is inert and out of the tab order while there is nothing to scroll toward. Renders a `<button>` element.

**Button Props:**

| Prop      | Type                                                                        | Default    | Description                                                            |
| :-------- | :-------------------------------------------------------------------------- | :--------- | :--------------------------------------------------------------------- |
| behavior  | `ScrollBehavior`                                                            | `'smooth'` | Native scroll behavior when clicked.                                   |
| direction | `MessageScrollerButtonDirection`                                            | `'end'`    | Transcript edge to scroll toward.                                      |
| render    | `Snippet<[props: HTMLButtonAttributes, state: MessageScrollerButtonState]>` | -          | Replaces the default `<button>`. Spread `props` onto the host element. |

**Button Data Attributes:**

| Attribute   | Type                | Description                                    |
| :---------- | :------------------ | :--------------------------------------------- |
| data-active | `'true' \| 'false'` | Whether the button can scroll toward its edge. |
