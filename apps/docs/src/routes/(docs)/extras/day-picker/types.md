## API Reference

### DayPicker

A calendar that shows one or more months and selects a single day, several days or a range. Renders a `<div>` element.

**DayPicker Props:**

| Prop                  | Type                                                                                                | Default   | Description                                                                                                   |
| :-------------------- | :-------------------------------------------------------------------------------------------------- | :-------- | :------------------------------------------------------------------------------------------------------------ |
| hidden                | `Matcher \| Matcher[]`                                                                              | -         | Days that are not rendered.                                                                                   |

| autofocus             | `boolean`                                                                                           | -         | Focus the focus target when the calendar mounts.                                                              |
