## API Reference

### Root

A command menu that filters, ranks and selects its items. Renders a `<div>` element.

**Root Props:**

| Prop                    | Type                                           | Default | Description                                                                                                                                                                                                                                                                  |
| :---------------------- | :--------------------------------------------- | :------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| label                   | `string`                                       | -       | Accessible label for the command menu, rendered visually hidden.                                                                                                                                                                                                             |
| defaultValue            | `string`                                       | -       | The value of the item selected at first. This is the uncontrolled counterpart of `value`.                                                                                                                                                                                    |
| value                   | `string`                                       | -       | The selected item's value. Bindable. While it is empty, Root selects the first item. A value that names no item is kept, and selects the first item with that value once one mounts.&#xA;&#xA;To start with a value without binding it, use the `defaultValue` prop instead. |
| onValueChange           | `(value: string) => void`                      | -       | Called on every change of the selected value, including the menu's own automatic selection.                                                                                                                                                                                  |
| disablePointerSelection | `boolean`                                      | `false` | Stops pointer movement from selecting items.                                                                                                                                                                                                                                 |
| filter                  | `CommandFilter`                                | -       | Scores an item against the search from 0 (hidden) to 1 (best). Defaults to `defaultFilter`.                                                                                                                                                                                  |
| onkeydown               | `KeyboardEventHandler<HTMLDivElement> \| null` | -       | Runs before the menu's keyboard handling. Call `event.preventDefault()` to skip it.                                                                                                                                                                                          |
| shouldFilter            | `boolean`                                      | `true`  | Set to false to turn off filtering and sorting, for example when the items come from a server search.                                                                                                                                                                        |
| vimBindings             | `boolean`                                      | `true`  | Enables Ctrl+N/J and Ctrl+P/K.                                                                                                                                                                                                                                               |
| loop                    | `boolean`                                      | `false` | Wraps the arrow keys around the ends of the list.                                                                                                                                                                                                                            |

### Item

An item in the command menu. Renders a `<div>` element.

**Item Props:**

| Prop          | Type                                          | Default | Description                                                                                        |
| :------------ | :-------------------------------------------- | :------ | :------------------------------------------------------------------------------------------------- |
| value         | `string`                                      | -       | The item's value. Defaults to its trimmed text content.                                            |
| onclick       | `MouseEventHandler<HTMLDivElement> \| null`   | -       | Runs before the item handles the click. Call `event.preventDefault()` to skip it.                  |
| forceMount    | `boolean`                                     | -       | Keeps the item visible whatever the search is.                                                     |
| keywords      | `readonly string[]`                           | -       | Extra words the search matches against.                                                            |
| onSelect      | `(value: string) => void`                     | -       | Called with the item's value on click or Enter.                                                    |
| onpointermove | `PointerEventHandler<HTMLDivElement> \| null` | -       | Runs before the item selects itself on pointer movement. Call `event.preventDefault()` to skip it. |
| disabled      | `boolean`                                     | `false` | Whether the item ignores the keyboard, the pointer and clicks.                                     |

**Item Data Attributes:**
