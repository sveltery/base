## API Reference

### Panel

Wraps resizable content, with optional size constraints and collapsible behavior. Renders a `<div>` element.

**Panel Props:**

| Prop          | Type                                                                                                                                        | Default  | Description                                                                                                                                                         |
| :------------ | :------------------------------------------------------------------------------------------------------------------------------------------ | :------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| collapsedSize | `number \| string \| undefined`                                                                                                             | `'0%'`   | The panel's size when collapsed.                                                                                                                                    |
| collapsible   | `boolean \| undefined`                                                                                                                      | `false`  | Whether the panel collapses when it is resized below its `minSize`.                                                                                                 |
| defaultSize   | `number \| string \| undefined`                                                                                                             | -        | The size the panel starts with. Without it, the group shares out the free space.                                                                                    |
| maxSize       | `number \| string \| undefined`                                                                                                             | `'100%'` | The largest size of the panel.                                                                                                                                      |
| minSize       | `number \| string \| undefined`                                                                                                             | `'0%'`   | The smallest size of the panel.                                                                                                                                     |
| onResize      | `((panelSize: ResizablePanelSize, id: string \| number \| undefined, prevPanelSize: ResizablePanelSize \| undefined) => void) \| undefined` | -        | Called when the panel's size changes, with the new size, the `id` prop and the previous size, which is `undefined` on mount.                                        |
| id            | `string \| number \| undefined`                                                                                                             | -        | Identifies the panel within its group. Falls back to a generated id. Saved layouts use it to match a size to its panel. The element also takes it as `data-testid`. |
| class         | `string \| undefined`                                                                                                                       | -        | CSS class for the inner element that holds the content, so the class does not interfere with the flex layout.                                                       |
| style         | `string \| null \| undefined`                                                                                                               | -        | Inline styles for the inner element that holds the content.                                                                                                         |

**Panel Data Attributes:**

| Attribute   | Type     | Description                         |
| :---------- | :------- | :---------------------------------- |
| data-panel  | -        | Present on every panel.             |
| data-testid | `string` | The panel's `id`, for test queries. |

### Group

Wraps a set of resizable panels, laid out horizontally or vertically. Renders a `<div>` element.

**Group Props:**

| Prop                    | Type                                               | Default                    | Description                                                                                                                                      |
| :---------------------- | :------------------------------------------------- | :------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| defaultLayout           | `ResizableLayout \| undefined`                     | -                          | The layout the group starts with, such as one `useDefaultLayout` restored. Read once at mount.                                                   |
| disableCursor           | `boolean \| undefined`                             | `false`                    | Whether to leave the cursor alone. By default, the group sets the cursor to show the resize direction while the pointer hovers or drags an edge. |
| onLayoutChange          | `((layout: ResizableLayout) => void) \| undefined` | -                          | Called while the layout changes. A pointer drag calls it on every move, so prefer `onLayoutChanged` for most cases.                              |
| onLayoutChanged         | `((layout: ResizableLayout) => void) \| undefined` | -                          | Called once the layout has changed. A pointer drag calls it when the pointer is released. Save layouts from this callback.                       |
| resizeTargetMinimumSize | `{ coarse: number; fine: number; }`                | `{ coarse: 20, fine: 10 }` | The minimum size, in pixels, of the area that starts a resize around a separator or a panel edge, for coarse (touch) and fine (mouse) pointers.  |
| disabled                | `boolean \| undefined`                             | `false`                    | Whether the panels of the group cannot be resized.                                                                                               |
| orientation             | `ResizableOrientation \| undefined`                | `'horizontal'`             | The direction the panels are laid out and resized in.                                                                                            |
| id                      | `string \| number \| undefined`                    | -                          | Identifies the group within the application. Falls back to a generated id. The element also takes it as `data-testid`.                           |
| children                | `Snippet`                                          | -                          | The panels and separators of the group.                                                                                                          |
| style                   | `string \| null \| undefined`                      | -                          | Inline styles for the group element. `display`, `flex-direction`, `flex-wrap` and `overflow` cannot be overridden.                               |

### Separator

A focusable handle between two panels that resizes them with the pointer and the keyboard. Renders a `<div>` element.

**Separator Props:**

| Prop  | Type                            | Default | Description                                                                                                          |
| :---- | :------------------------------ | :------ | :------------------------------------------------------------------------------------------------------------------- |
| id    | `string \| number \| undefined` | -       | Identifies the separator within its group. Falls back to a generated id. The element also takes it as `data-testid`. |
| style | `string \| null \| undefined`   | -       | Inline styles for the separator. `flex-grow` and `flex-shrink` cannot be overridden.                                 |

**Separator Data Attributes:**

| Attribute      | Type                                | Description                                                                                                      |
| :------------- | :---------------------------------- | :--------------------------------------------------------------------------------------------------------------- |
| data-separator | `'inactive' \| 'hover' \| 'active'` | Whether the pointer is over the separator's hit area (`hover`), dragging it (`active`), or neither (`inactive`). |
| data-testid    | `string`                            | The separator's `id`, for test queries.                                                                          |

### ResizablePanelActions

```typescript
type ResizablePanelActions = {
	/**
	 * Collapse the Panel to its `collapsedSize`.
	 *
	 * ⚠️ This method will do nothing if the Panel is not `collapsible` or if it is already collapsed.
	 */
	collapse: () => void;
	/**
	 * Expand a collapsed Panel to its most recent size.
	 *
	 * ⚠️ This method will do nothing if the Panel is not currently collapsed.
	 */
	expand: () => void;
	/** Get the current size of the Panel in pixels as well as a percentage of the parent group (0..100). */
	getSize: () => { asPercentage: number; inPixels: number };
	/** The Panel is currently collapsed. */
	isCollapsed: () => boolean;
	/**
	 * Update the Panel's size.
	 *
	 * Size can be in the following formats:
	 * - Percentage of the parent Group (0..100)
	 * - Pixels
	 * - Relative font units (em, rem)
	 * - Viewport relative units (vh, vw)
	 *
	 * ℹ️ Numeric values are assumed to be pixels. Strings without explicit units are assumed to be percentages (0%..100%). Percentages may also be specified as strings ending with "%" (e.g. "33%") Pixels may also be specified as strings ending with the unit "px". Other units should be specified as strings ending with their CSS property units (e.g. 1rem, 50vh)
	 */
	resize: (size: number | string) => void;
};
```

### UseDefaultLayoutOptions

```typescript
type UseDefaultLayoutOptions = {
	/**
	 * Debounce save operation by the specified number of milliseconds; defaults to 100ms
	 *
	 * @deprecated Use the `onLayoutChanged` callback instead; it does not require debouncing
	 */
	debounceSaveMs?: number;
	/**
	 * For Groups that contain conditionally-rendered Panels, this prop can be used to save and restore multiple layouts.
	 *
	 * ℹ️ This prevents layout shift for server-rendered apps.
	 *
	 * ⚠️ Panel ids must match the Panels rendered within the Group during mount or the initial layout will be incorrect.
	 */
	panelIds?: string[] | undefined;
	/** Storage implementation; supports localStorage, sessionStorage, and custom implementations. */
	storage?: ResizableLayoutStorage;
} & (
	| {
			/**
			 * Group id; must be unique in order for layouts to be saved separately.
			 * @deprecated Use the `id` param instead
			 */
			groupId: string;
	  }
	| {
			/** Uniquely identifies a specific group/layout. */
			id: string;
	  }
);
```
