## API Reference

### Root

A form that shows one item at a time and validates each before it moves on. Renders a `<form>` element.

**Root Props:**

| Prop         | Type                                     | Default | Description                                                                                                  |
| :----------- | :--------------------------------------- | :------ | :----------------------------------------------------------------------------------------------------------- |
| defaultItem  | `string`                                 | -       | The item to start on when `item` is undefined. Defaults to the first enabled item.                           |
| item         | `string`                                 | -       | The active item name. Bind it to follow and set navigation.                                                  |
| items        | `readonly QuestionnaireItemDefinition[]` | -       | Item order, required flags and choice values, so the server renders the active item, progress and shortcuts. |
| novalidate   | `boolean`                                | `true`  | Turns off the browser's constraint validation UI. Questionnaire validation still runs.                       |
| onItemChange | `(item: string) => void`                 | -       | Called when navigation moves to another item.                                                                |
| shortcuts    | `QuestionnaireShortcutMode`              | -       | Gives each choice a letter or number key that selects it.                                                    |

**Root Data Attributes:**

| Attribute      | Type | Description                                                       |
| :------------- | :--- | :---------------------------------------------------------------- |
| data-current   | -    | The 1-based position of the active item.                          |
| data-first     | -    | Present when the first item is active.                            |
| data-last      | -    | Present when the last item is active.                             |
| data-shortcuts | -    | The shortcut mode, `letters` or `numbers`, when shortcuts are on. |
| data-total     | -    | The number of enabled items.                                      |

### Item

One step of the questionnaire, hidden while another step is active. Renders a `<fieldset>` element.

**Item Props:**

| Prop           | Type                                        | Default | Description                                                              |
| :------------- | :------------------------------------------ | :------ | :----------------------------------------------------------------------- |
| name           | `string`                                    | -       | Unique within the questionnaire, and the form field name of its answers. |
| multiple       | `boolean`                                   | `false` | Renders fixed choices as checkboxes.                                     |
| onStatusChange | `(status: QuestionnaireItemStatus) => void` | -       | Called when the item becomes answered, skipped or unanswered.            |
| disabled       | `boolean`                                   | `false` | Removes the item from progress, navigation, validation and submission.   |
| required       | `boolean`                                   | `false` | Whether the item needs an answer. A required item cannot be skipped.     |
| invalid        | `boolean`                                   | `false` | Marks the item invalid from an external validator.                       |

**Item Data Attributes:**

| data-invalid  | -    | Present when the item failed validation or `invalid` is set. |
| data-active   | -    | Present when the item is the active one.                     |
| data-multiple | -    | Present when the item takes more than one choice.            |
