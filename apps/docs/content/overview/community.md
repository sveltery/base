## Sveltery UI

[Sveltery UI](https://ui.sveltery.dev) uses Sveltery Base as its unstyled foundation. If you want Tailwind-styled wrapper components and higher-level APIs without building that layer yourself, start from Sveltery UI.

## Base UI

Sveltery Base is a port of [Base UI](https://base-ui.com). The [Base UI community page](https://base-ui.com/react/overview/community) lists styled libraries and ports to other frameworks.

## Get help and contribute

### GitHub

Sveltery Base is an open-source project.
If you want to file a bug report, ask a question, or contribute, visit our [GitHub](https://github.com/sveltery/base).

## Stay up to date

### npm

New versions are published to [npm](https://www.npmjs.com/package/@sveltery/base).

Release notes are published on our [releases](/overview/releases) page as well.
