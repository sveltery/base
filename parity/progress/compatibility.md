Range normalization, raw callback values, default formatting, synchronized status attributes, internal indeterminate style removal, native overrides and Root presentation x port the actual pin. No local behavior correction is introduced. Private Intl caching omits only the unreachable nullable formatter input because Progress invokes it solely after numeric normalization; cache key/format semantics are unchanged. Equal, reversed and nonfinite bounds preserve the exact pin's arithmetic. Paired browser characterization is required before classifying a shared defect; no opportunistic correction is authorized by this port.

Passing a divergent assertion, a merge or a documentation check establishes neither parity nor deviation acceptance. The named API substitutions above use the accepted framework baseline described in central T-01 and A-01; any additional observable timing difference needs its own evidence and decision. Browser execution, automatic and independent exact-head reviews, shared public integration and full package consumers remain required in [verification](verification.md). Complete assistive-technology behavior and arbitrary uncommitted framework batching remain unclaimed.
