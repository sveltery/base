## Bounded implementation and ownership

Only `Collapsible.Panel` and a feature-owned native transport helper, tentatively `panel/useCollapsiblePanelDimensions.svelte.ts`, change. Existing canonical rendering, native style serialization, ref fanout and all shared helpers remain unchanged. `useCollapsiblePanel` business branches, direct alignment/name/duration writes, state/cache, listeners and completion order remain unchanged.

1. Keep the Source height/width CSS variable names and their SSR `auto` defaults in the existing ordered Panel props. Public resolved style remains rightmost, followed by Source's initial animation-name suppression. Remove reactive measured values from that CSS-text props record; only the two defaults remain there.
2. Forward one native attachment through the real canonical renderer props, using Svelte's attachment key. The attachment receives the actual rendered host, including a forwarding snippet or replacement host. It creates a native effect whose only writes are `--collapsible-panel-height` followed by `--collapsible-panel-width`. Each measured value becomes pixels; `undefined` becomes `auto`, as in Source. No style text is assigned on the actual host by the attachment.
3. The effect reads current height, width and the resolved public authored style. Reuse unchanged canonical `toNativeStyle` for native string/object representation. A detached owner-document CSS declaration parses that authored text; read only the two named variables and their priorities. A present authored variable wins, including `auto`, custom values and `!important`; otherwise write the internal measured/auto value. No arbitrary-property iteration, host-style snapshot, renderer property diff or restoration of alignment/duration/name is added. String duplicate declarations follow the browser's own parsing, and record representation follows the accepted canonical serializer.
4. Native authored style updates still use the unchanged renderer and can replace unrelated imperative styles. They also reschedule the two-variable effect so measured values are not accidentally replaced by the static SSR defaults when the author changes another property. Removing an authored variable or setting it `undefined` restores the current internal value; removing the whole public style follows native renderer semantics. Any inherent authored-change observations must be verified against bare Svelte and recorded separately with zero divergent credit.
5. The effect's lifetime belongs to the attached host. Native detach disposes it; it cannot write a later dimension update to a disconnected or replaced host. A new host receives current values through its own attachment. Cleanup does not snapshot/replay authored props, reset arbitrary CSS or clear Source's rendered dimension values from a disconnected old host. Source itself leaves the last rendered dimension declarations on a removed host. An opaque snippet that overrides the forwarded style after spreading must be characterized as a native consumer boundary; no hidden DOM observer or renderer emulation is proposed.

- A transition open synchronously writes the four alignment properties to `initial!important`, measures height then width, updates dimensions, and returns the layout cleanup.
