# Native Toast parts foundation

Authority: Base UI v1.8.0 `47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c`, `toast/{content,title,description,action,close}` plus `utils/useToastLabelPart.ts`, `utils/isRenderableNode.ts` and native `internals/use-button/useButton.ts`. MIT attribution is retained in component sources, test ports and [UPSTREAM_LICENSE](UPSTREAM_LICENSE).

`Content`, `Title`, `Description`, `Action` and `Close` render native div, h2, p and button elements. State class/style callbacks, native props and bindable node refs use the existing internal Element adapter. Content observes its owner-window resize and mutation APIs, recalculates Root height, and disconnects both observers on element removal. Title/Description register IDs only while content renders; cleanup belongs to one registration so an older part cannot clear its replacement. Svelte `$props.id()` provides stable generated IDs, and explicit ID changes register reactively. Layout registration runs on the client, matching the upstream layout-effect labels; initial SSR markup does not claim registered root ARIA relationships before hydration.

Content accepts a Svelte child snippet. Label, Action and Close children accept the documented `ToastContent` scalar/snippet union. Label children use `children ?? toast.title/description`; Action uses `toast.actionProps.children ?? children`. Nullish labels fall back, while false, true and empty string suppress the element; numeric zero renders. Snippets are treated as declared renderable content. Actual snippets that emit text/elements are covered; introspecting an arbitrary empty or conditionally empty snippet output is deferred and earns no content/render-function parity credit. ReactNode arrays/elements, replacement `render` and non-native buttons are not public contracts in this bounded slice.

Action scalar props come from the toast after component native props; handlers compose in the pinned order (manager then component). Component state class/style is resolved after manager Action class/style. `preventBaseUIHandler()` stops the preceding handler, while `preventDefault()` alone does not cancel Close. The native button adapter preserves upstream `type="button"`, tabindex, external scalar overrides and part-level disabled event gating. Pinned Action precedence allows manager `actionProps.disabled` to override the native disabled attribute even when the component's disabled flag remains the event guard; the explicit conflict regression preserves this behavior. Action does not close by itself. Close owns focus state for collapsed `aria-hidden` and routes close through the Provider store.

The complete direct-port inventory is [parts-ports.json](parts-ports.json): T:29/49/70/96/172/201/229, D:28/49/75, A:30/47 and C:30. All original direct assertions execute, including absence, label equality, default text, numeric zero, content removal, intermediate older/newer registration states and Close presence before/after clicking. React `render`, `rerender`, `act` and `user.click` are adapted to actual Svelte `mount`, `flushSync`, component methods and native click/focus; shared List/Button markup and manager content are retained. Every Root explicitly opts out of gestures with `swipeDirection={[]}`. No shared conformance declaration or replacement-render leaf is promoted.

Separate supplements exercise reactive IDs/types, all nonrenderable scalar values, nullish precedence, semantic snippets, Action handler/prop/state class/style precedence, event prevention, Close focus/disabled behavior and observer ownership. They earn zero upstream leaf credit. Local jsdom execution passes; exact-head checks and hosted browser acceptance remain parent-owned gates. The immutable 196-declaration source inventory stays unchanged. Label SSR/hydration browser evidence is recorded by the paired rendering harness, separately from these DOM ports.
