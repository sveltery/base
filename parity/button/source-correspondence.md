Before repair, actual main `c4ae7fc` used `button/props.ts` through legacy `dialog/Element.svelte`. This independently resolved a reduced non-composite useButton algorithm, duplicated click synthesis and state attributes, omitted composite inference and nested canonical composition, and added the PR17 disabled mousedown default cancellation.
