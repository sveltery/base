Reference: Base UI 1.8.0 immutable `47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c`, MIT. The facade is an integration extension. Its adapters do not earn unchanged Base UI declaration credit. The [actual local import graph](local-graph.json) records all reachable runtime/type imports and file hashes from Form, the remote namespace, Input and the authored checked/group families. `RemoteNativeControl` is the one necessary native-host extension where source Control's string input contract cannot represent selected arrays/files/options. It has no independent controlled state, selection store, reset listener, event replay or attachment kernel. Text and numeric input use the original Control. Native option serialization and business logical names remain separate at the shared native-input-name context.
