`RemoteNativeControl` is the one necessary native-host extension where source Control's string input contract cannot represent selected arrays/files/options. It has no independent controlled state, selection store, reset listener, event replay or attachment kernel. Text and numeric input use the original Control. Native option serialization and business logical names remain separate at the shared native-input-name context.
