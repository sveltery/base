# UseRender compatibility decision

Reference: Base UI v1.8.0 `47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c`, [public useRender](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/use-render/useRender.ts), [private rendering closure](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/internals/useRenderElement.tsx), and [merged-ref lifecycle](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/utils/src/useMergedRefs.ts). Derived code/assertions retain MIT attribution.

Upstream `useRender(params)` returns a ReactElement or null with conditional return types. Locally `<UseRender {...params}/>` renders Svelte markup, with a replacement snippet rather than a cloneable ReactElement. The component/name/return API change is a specific [delegated PM design decision](https://github.com/sveltery/base/pull/40#pullrequestreview-5396533264), recorded against `8b24a8860a448122477298427b1ab1925f0ca909` on October 2, 2026; it is not one of the five historical syntax substitutions and no explicit user acceptance is recorded. All seven return-type assertions remain divergent/unported and receive zero credit. Public props remains an ordinary object; array/getter sources and state-dependent class/style callbacks belong to the private source closure.

Native callback/object/array refs are fanned out separately from prop merge; callback cleanup supersedes null delivery, while callbacks with no cleanup receive null, matching the pinned merged-ref rule. Bindable actual-host `element` is a Svelte observation adaptation following A-01's initial undefined/host/null lifecycle. Replacement-owned refs use host attachments, and snippets merge their owned props after supplied props; neither a snippet nor its internals are cloned or introspected. Snippet-owned attachment lifecycle is separate from the supplied fanout; it cannot contribute its ref to React's single cloned-element merged-ref callback. Individual ref identity and empty slots determine memoization: the fixed form compares four positions and the array form also compares length, preserving the actual pinned comparator. Native string CSS preserves the authored cascade rather than accepting React CSS objects. Native events preserve independent native-default prevention and Base UI handler suppression through the existing mergeProps baseline.

React lazy/Suspense, Flight/RSC and invalid-render/function-name diagnostics remain unimplemented. Their twelve internal source sites/fifteen variants and the seven divergent type assertions are uncredited. DirectionProvider and CSPProvider are independent foundations, not dependencies of this source closure. This change does not migrate existing components or claim complete shared-helper/library parity.

Evidence: 45 focused actual Svelte DOM assertion ports/supplements, three exact-source getter ownership regressions, immutable source trace and isolated internal tarball SSR/native types pass locally. The [verification history](verification.md) preserves the failed review candidate and distinguishes repaired-source execution from earlier superseded runs. Secured paired browser execution and exact final-head/public package gates remain required before PM approval/merge. Proposed [PR #40](https://github.com/sveltery/base/pull/40) anchors the delegated PM public design review; immutable passing browser checkpoints will be recorded when available. Implementation approval is not merge approval or explicit acceptance of product differences.
