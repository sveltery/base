## Proposed bounded shared framework view

The original helper returns JSX containing Provider → handle attachment → conditional interactions → children. The current native Dialog Root contains this setup/markup directly. Extract its existing setup and composition into ONE private generic `dialog/root/DialogRootView.svelte`, reused by public Dialog Root and AlertDialog Root. This is a real native framework rendering/context boundary; no business algorithm moves or changes.

Private inputs are mode, rootProps, floatingId and bindable actions. Each public Root keeps `$props.id()` in the existing public component lifetime, forwarding the ID to the shared view. Each public Root retains exported close/unmount functions through native bound actions. The shared view initializes the SAME helper exactly once, owns context, handle/interactions/children ordering, actions publication and destroy cleanup. Mode is private; Dialog's public props/behavior do not change. Root PM must approve this precise lease before shared Root edits. Alternatives or observable lifecycle changes require renewed review.
