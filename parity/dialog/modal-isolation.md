## Implementation and adapters

[isolation.ts](../../packages/base/src/lib/overlay/isolation.ts) is a small native DOM primitive. Each document has independent aria-hidden/marker ownership maps in a WeakMap. No document is read during module evaluation or SSR. Last release removes the document entry; claims release detached elements too. One Popup attachment effect synchronizes open/modality with this primitive. It does not derive or copy Svelte state. Existing focus entry/return, Tab/radio discovery, IME, dismissal, stack ordering, animation and presence logic are unchanged.

[Svelte](../../apps/fixtures/src/lib/ModalIsolationFixture.svelte) and [real React](../../apps/fixtures/src/lib/modal-isolation-reference.ts) fixtures share `/modal-isolation`. Framework syntax, native Svelte style strings versus React style objects, and cleanup-managed imperative owner commands are adapter differences. Trusted clicks open and close in the browser; imperative commands model owner prop changes and conditional rendering. The invalid-but-existing empty aria-hidden value is installed through the same native attribute API in each adapter to test byte preservation without weakening public typings.

[DOM tests](../../packages/base/tests/dom/modal-isolation.test.ts) contain **20 paired executions** (ten per framework) plus **one separate native iframe ownership regression**. [Browser tests](../../tests/browser/dialog-modal-isolation.spec.ts) contain **20 paired secured Chromium executions** and use rendered role queries plus the live-region accessible snapshot. DOM observations do not substitute for browser accessibility evidence. Existing focus ownership and all prior browser probes remain in the full suite.

## Limits

This is bounded Dialog accessibility isolation, not complete accessibility or Floating UI equivalence. The tested nested and sibling sequences mount a new second portal after the first is open. Simultaneously initially open siblings, already-mounted sibling portals, live modality changes while a child body portal is open, explicit target relocation, shadow-root live-region discovery, and arbitrary external DOM insertion/attribute edits during isolation remain unverified. Traversal snapshots existing outside elements when an attachment's open/modality synchronization runs; it does not observe arbitrary document mutations. External mutation conflict resolution and broader externally owned marker behavior are unimplemented.

Live-region exemption is covered without using a Toast substitute. Cross-component Menu/Select/AlertDialog/Drawer/Toast portal ownership, Toast viewport interaction routing/announcements and native-inert ownership mixtures remain unimplemented and uncredited. Nonmodal logical Tab order and focus guards, detached handles/payloads, Viewport, Drawer and Toast are excluded from this slice. Screen-reader product testing and browsers other than secured Chromium are not claimed.
