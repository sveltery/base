# Dialog whole-source audit

Reference: Base UI 1.8.0, immutable commit `47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c`, MIT. The [original graph](source-graph.json) records all 138 static import/re-export modules and 631 runtime/type edges, including unselected barrel branches, with original SHA-256 hashes and immutable URLs. This is a dependency inventory, not a parity or acceptance claim.

PR42 predates the source-porting directive. The first whole-source audit finds the following real gaps. Historical green execution and the earlier bounded handle PM decision do not clear them. The delivery boundary now includes every Dialog public part/type and its actually used reusable popup business closure. Drawer/AlertDialog public families and positioning middleware remain outside this PR; their distinct source branches are recorded when shared helpers expose them.

React-only state/context/ref/effect/render/StrictMode machinery will use native Svelte runes/context/snippets/attachments/lifecycle under the user's native directive. Inherent native differences will retain actual Svelte defaults and be measured separately. Business branches, cancellation, callback order, cleanup and upstream quirks remain source-owned. No ordinary assertion credit changes at this audit checkpoint. Every implementation row remains incomplete until used code, meaningful execution and fresh independent source/native/maintainability review exist on the final head.

The first dependency checkpoints port the original Store mutation/recursive notification body to `utils/store/Store.svelte.ts`; `SvelteStore.svelte.ts` replaces React subscription/render helpers with native raw snapshots, selected reads, live prop readers and cleanup-owned native effects. Original NullStore no-op mutations, PopupTriggerMap reverse-index validation, popup initial state/selectors/open-state, BasePopupHandle attachment-stack lookup, DialogStore callback/cancellation/open event sequence, and DialogHandle payload write ordering now exist under their original module boundaries. Native lifecycle/registration helpers retain separate source symbols in `popupStoreUtils.svelte.ts`. They are staged dependencies; the existing Dialog still consumes its historical controller until the component integration checkpoint.

Focused native store regressions execute 6/6: recursive notification abort, Object.is snapshot writes, Dialog callback/dispatch order and the immediate canceled prevent-unmount flag write, controlled selectors/closing trigger retention, inert fallback registration, and shared handle attachment-stack/payload cancellation. These are supplements, with ordinary assertion credit 0. Package build and native type checking pass at this checkpoint; no component/browser or final independent review is claimed.

Original event/platform utilities are shared under `floating-ui/utils/event.ts` and `utils/platform/`. Composite now imports the single exact `stopEvent` body instead of a private duplicate. Floating focus reexports the already ported original Composite visibility/navigation body rather than copying it. Source DOM tabbable/shadow traversal, marker reference counting, enqueue-focus and node traversal bodies are under `floating-ui/utils/`; synthetic event wrappers/types are directly replaced by native Events. The complete original graph preserves their immutable hashes.
