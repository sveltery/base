# Dialog whole-source audit

Reference: Base UI 1.8.0, immutable commit `47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c`, MIT. The [original graph](source-graph.json) records all 138 static import/re-export modules and 631 runtime/type edges, including unselected barrel branches, with original SHA-256 hashes and immutable URLs. This is a dependency inventory, not a parity or acceptance claim.

PR42 predates the source-porting directive. The first whole-source audit finds the following real gaps. Historical green execution and the earlier bounded handle PM decision do not clear them. The delivery boundary now includes every Dialog public part/type and its actually used reusable popup business closure. Drawer/AlertDialog public families and positioning middleware remain outside this PR; their distinct source branches are recorded when shared helpers expose them.

React-only state/context/ref/effect/render/StrictMode machinery will use native Svelte runes/context/snippets/attachments/lifecycle under the user's native directive. Inherent native differences will retain actual Svelte defaults and be measured separately. Business branches, cancellation, callback order, cleanup and upstream quirks remain source-owned. No ordinary assertion credit changes at this audit checkpoint. Every implementation row remains incomplete until used code, meaningful execution and fresh independent source/native/maintainability review exist on the final head.
