`Toggle` renders a native button by default, with `aria-pressed`, `data-pressed` when pressed and `data-disabled` when disabled. `defaultPressed=false`, `disabled=false`, `nativeButton=true`. The initial controlled mode and initial default remain fixed for the component lifetime. A controlled click requests a change and waits for the owner's prop update. If a controlled prop later becomes undefined, the original default is used and internal writes remain disabled, matching the pinned `useControlled`. An initially uncontrolled Toggle ignores a later controlled prop. `onPressedChange(nextPressed, details)` runs before commit; `details.reason` is `none`, its event is the native click, and no trigger is supplied. `details.cancel()` vetoes the state write without canceling native defaults or propagation.

The component intentionally strips **form, type and value**, including explicit undefined/null type. The default button host always receives `type=button`, even with `nativeButton=false`. It cannot be converted into submit/reset through those component props and does not contribute its value to FormData. Native reset leaves pressed state alone. Replacement snippets retain responsibility for their own host props, as upstream render replacements do. This preserves the upstream source and is an exception to native form participation, rather than a new form abstraction. In particular, a SvelteKit remote form's button submission props cannot turn this Toggle into a submit control. Other native props and enumerable attachment symbols pass through; independent form controls and their direct remote-form spreads are untouched.

Non-native render snippets use `nativeButton=false`, role/button focusability, Enter keydown and Space keyup activation, including native links. Disabled native hosts use disabled; disabled non-native hosts use aria-disabled and tabindex=-1. Toggle has no `focusableWhenDisabled` API. The existing button helper is reused without changes. Its **D-03 disabled-mousedown correction is inherited**: local custom disabled Toggle prevents the default while the pinned React helper only suppresses the consumer callback. This difference earns no parity credit and its specific acceptance is not recorded. See the [compatibility record](compatibility.md) and central [D-03](../../docs/upstream-differences.md#d-03-disabled-chorded-mousedown-default-focus).

Composition follows the established Svelte API substitutions: `class` instead of `className`, CSS strings, children/render snippets, native event props, `bind:ref` and attachments. `render(props, state, children)` receives `{pressed, disabled}` and must spread the supplied props, including attachment symbols. Use `mergeProps(props, ownProps)` to compose replacement handlers. Replacement click runs before component click, which runs before internal change. `preventBaseUIHandler()` suppresses earlier handlers without canceling defaults or bubbling; native `preventDefault()` alone does not veto the pressed change. The initially undefined ref/host/null-cleanup contract follows the approved [A-01 adaptation](../../docs/upstream-differences.md#a-01-approved-proposed-core-audit-repairs-and-substitutions).
