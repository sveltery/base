Shared utility paths above are under `packages/utils/src/lib`; `internals/useValueChanged.svelte.ts` remains under `packages/base/src/lib` and imports real Utils subpaths. The [package successor](../utils-package/README.md) records the full move, current source graphs and additional scheduler/owner/formatter/store boundaries. Historical source/assertion receipts remain immutable. Original React Dispatch, SetStateAction, RefObject and EffectCallback types become equivalent local setter/ref/effect shapes. The controlled value API has the explicit accessor substitution. Runtime imports remain free of React and SvelteKit. Original framework-only SafeReact and render bookkeeping are mapped above, rather than concealed as missing business logic.

Implementation order is empty/logger/ref, mount/stable/layout, controlled/timeout, then value-change tracking. Current user direction keeps Svelte defaults for inherent framework behavior. [compatibility.md](compatibility.md) records precise source/native observations and decisions; [verification.md](verification.md) records executed checks; this does not approve unrelated differences. Final source review, CI and dependent component/browser acceptance are separate gates. These helpers alone establish no Input/Field, rendering, or whole-library parity.
