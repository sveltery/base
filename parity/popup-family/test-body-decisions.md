# Original popup-family test reading decisions

All 37 own family test/type-spec bodies and all 15 selected repository test-helper bodies were read in full at immutable Original `47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c`. The receipt lists hashes and remaining Source bodies explicitly.

Popover's tests require callback-before-state changes, canceled close and retained-unmount ownership, external-open versus hover-open closure, the patient click timer, trigger handoffs, stacked handle attachments and fallback registration migration without consumer-ref churn. Modal focus trapping depends on actual Close registration; without Close, trigger focus guards and Tab dismissal remain relevant. Focus defaults and explicit element/function/false/null targets, removed or hidden focus targets, touch scroll locking, shadow-root outside press, nested Menu/Combobox consumers and animation completion stay separate test boundaries. Positioner tests use actual measured DOM geometry and canonical middleware, including logical sides, collision padding, disabled tracking and viewport-dependent transform positioning. Viewport tests require current-container remounts, inert previous content, rapid handoffs and retained closed-trigger remount behavior.

PreviewCard's tests require 600ms open and 300ms close defaults, synchronous zero-delay opening, immediate active-trigger handoff, delay restoration after full close lifecycle, retained close-transition reopening, resolved-active-trigger loss with cancellation, independent root ownership and payload association. Nested preview hover timers must preserve parents and synchronize closure. Multiline tests capture the latest hovered line before opening, retain that line while open, recapture on reopen, reject stale coordinates after trigger changes and clear coordinates on focus or completed close. Source tests that override client rects remain explicit author fixtures; the implementation uses the default platform and real measured nodes.

Tooltip's tests require provider takeover and instant animation phase, pending-open cancellation by pointerdown/click, root/trigger disabled precedence without adding native disabled, focus-versus-hover instant reasons, hoverable popup trips, axis-specific inertness and listener cleanup across disabling/closing/reopening. Nested triggers suppress only hover-owned parents, restart local parent-area delay, cancel reentry timers on nested return or leave, support detached handles and composed shadow paths, permit disabled nested triggers to fall through, and keep focus/controlled-open parents. Viewport tests explicitly wait on live animations, retain latest rapid-transition content and restart entry transitions after lagging payload remounts. React suspended-hydration ordering fixtures need native Svelte hydration witnesses and zero automatic unchanged credit for renderer-specific mechanics.

The shared conformance helper enumerates class, prop/style spreading, ref and render composition. Shared popup conformance includes controlled/uncontrolled behavior, keep-mounted variants and an explicitly skipped exit-animation test; its existing skip is preserved as evidence and gives no passing credit. Framework wrappers (`act`, `flushMicrotasks`, React renderer, React JSX/ref clones) need native harness substitutions, with business assertions preserved only when their trigger, precondition and observation remain equivalent. Native Svelte portal events follow actual DOM propagation; React portal bubbling bookkeeping is an inherent renderer difference, not a new event emulation requirement.

The six direct parameterized declaration sites and the three Root `describe.for` fixture families still require explicit expansion in the assertion inventory. Browser/JSDOM skips, early returns, strict-mode ref replay variants, helper-generated conformance cases, and negative type samples must be reported separately. Sibling consumers such as Menu, Combobox and Toolbar are dependency fixtures, not authorization to install unselected business bodies. Suspected Original bugs are preserved until a physical exact-pin reproducer and separate decision establish a correction.
