This is an unapproved precode proposal. It does not clear final native closure comparison, shared helper leases, runtime work or merge. ## Scope and source boundaries

Implement the complete nineteen-part pinned Select namespace: Root, Label, Trigger, Value, Icon, Portal, Backdrop, Positioner, Popup, List, Item, ItemIndicator, ItemText, Arrow, ScrollDownArrow, ScrollUpArrow, Group, GroupLabel and Separator. Keep SelectScrollArrow as the shared internal arrow implementation and retain Indicator's conditional outer/Inner composition. Root is wrapperless and owns the actual hidden input(s).

The [selected source graph](selected-source-graph.json) records every imported symbol, caller, type/runtime edge, whole file and top-level member hash. Its 178 modules are a conservative selected-module review closure, not 178 required new business implementations. Non-barrel imported modules retain their complete bodies for manual review. Type-only paths (for example FieldRoot/Fieldset/Form declarations and gridNavigation) remain distinct from used runtime composition. The broader 195-module source closure and 741-module test closure include unselected barrel exports for provenance. They do not create an unrelated Dialog/Menu/Combobox implementation prerequisite.

The actual Root dependencies are useControlled(value/open), SelectStore selectors/commands, real Field registration/validation and labelable context, transition/completion, the floating root store/context, useClick(mousedown), useDismiss(default sloppy), useListNavigation and useTypeahead. Select Item uses CompositeList/useCompositeListItem registration plus the shared useButton; it does not replace floating list navigation with CompositeRoot. Positioner owns CompositeList and its map-change reconciliation. Popup consumes the actual floating focus manager, positioning, scroll lock, CSP/style and owner-document helpers. Hover-to-open is not a Select Root import; item hover navigation remains a useListNavigation branch.

## Hidden forms, optional Field/Form and native defaults

Root's real shared validation input is rendered after children within Root context. Single mode serializes through stringifyAsValue and carries the logical source name; multiple mode leaves that common input nameless with empty value and renders one real hidden input per selected value when name is truthy. Required remains active on the common input until multiple has a selection. Disabled, readOnly, form, autoComplete, inputRef, validation refs, visually-hidden styling and source derived hidden ID remain exact source obligations.

Native Svelte must own the actual input value/default/reset/SSR/hydration and native event phases. Do not retain React's hydration suppression, synthetic change tracking, controlled-restoration or activation replay solely for renderer parity. Root business value/dirty/filled/validation and hidden serialization must remain coherent with the selected owner. Paired literal React/Svelte witnesses establish any native reset/default timing difference; divergent observations earn zero unchanged assertion credit.

Autofill must retain forced mounting followed by deferred lookup: disabled/readOnly/prevented exits; multiple scalar autofill exits; serialized and item-label lowercase matching then rendered text fallback; non-null match requests setValue with reason none. Value cancellation must not mark dirty or validate through an independent autofill path. Guard only genuinely obsolete deferred work under native lifetime; do not add an unconditional React commit replay kernel.

Real Field/Form remains optional. Schema-free/global Select must work without providers and with existing external form libraries. Authored name/id/errors, value/default/open, refs/callbacks and validation mode must remain available. Logical error/registration name and serialization-name override use existing canonical separation where explicitly present; never infer Kit prefixes or import Kit runtime.

Typed remote Form composition remains an integration extension: retain actual accessor-derived args/names, manual overrides, error/issue precedence, direct native descriptor spreads, programmatic updates and native reset. Existing remote native select is not a Select feature implementation. A later separately approved integration must route a consumer Select.Root/Trigger render through real source registration/validation without inventing another value store or reset listener. Public remote namespace selection changes are shared integration scope and need their own lease.
