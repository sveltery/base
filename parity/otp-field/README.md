Native differences under the user directive are separate from source business fidelity: native `oninput`/event props; snippets/actual-host refs; SSR-stable native IDs; no React owner stack or commit restoration; noncancelable native focus/blur default prevention; canceled native typing can retain the edited slot DOM while source whole-value state/focus/completion remain canceled. Paired DOM tests already reproduce the canceled-typing and focus/blur vectors on actual Source/React19.2.8 and Svelte; secured witnesses remain a separate gate. Divergent cases receive zero ordinary parity credit. The default OTP Input uses native functional `bind:value` through the canonical renderer-supplied props: the existing composed input handler is the sole whole-value mutation handler, and the getter synchronizes each merged slot value after accepted updates. Direct native binding probes and actual paired tests verify that a multi-character edit with an unchanged first character settles the one-character slot before external form validity/submission, without callback duplication or a restoration engine. Authored render snippets own their native input composition. Original code-point clamp/UTF16 slot/completion bugs are preserved and reproduced in both actual runtimes ([issue #56](https://github.com/sveltery/base/issues/56)).
