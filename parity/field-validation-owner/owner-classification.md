## Independently checked ownership and order

FieldRootInner constructs one FieldValidationOwner and passes detached bound change/commit to real registration. Register replacement cancels prior work before publishing the new source; baseline capture is once per Field. Dirty state precedes change validation. Validation commit identity, revalidate early exits, timer clear position, native/custom/external error precedence and custom-validity displacement guards retain the immutable business.

LabelableProviderOwner captures parent context before publishing itself. It retains explicit null, empty-registry selection retention/reset, selected-control preservation, live imperative message updates, external/parent/local description order and final deduplication. Description/Error use detached setters; group uses detached registerControlId, so arrow binding is required. Association callers construct once in native initialization and retain update-before-observer setup, captured source/root/view, observer filter and disconnect; lookup remains wrapping label, matching next sibling, then labels[0].

The newly assigned LabelableId and Enter owners require separate precode capture, meaningful actual public/cancellation/lifetime evidence, fresh packed artifacts and exact-final-head body review. This audit establishes classifications and scoped inspection, not final acceptance. Missing secured local browsers remain incomplete and require hosted completion; #73 integration and foreign-owner gaps remain explicit.
