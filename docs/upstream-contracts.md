## Dialog: exact public parts and behavior

Namespace exports: **Root, Trigger, Portal, Backdrop, Viewport, Popup, Title, Description, Close, createHandle, Handle**. [Pinned namespace](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/dialog/index.parts.ts).

| Part        | Element / extra props / defaults                                                                                                                                                                                                   | Observable contract                                                                                                                                                                                                                                                                                                                                                          |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Root        | No element. `open`; `defaultOpen=false`; `modal=true`; `disablePointerDismissal=false`; `onOpenChange`; `onOpenChangeComplete`; `actionsRef`; `handle`; `triggerId`; `defaultTriggerId=null`; children or payload render function. | `modal=true`: trap focus, lock page scroll, block outside pointer interactions. `false`: permit outside interaction. `'trap-focus'`: trap focus while permitting page scroll and outside pointer interactions. `disablePointerDismissal` also blocks nonmodal focus-out dismissal. Actions expose `close()` and `unmount()`. Callback details add `preventUnmountOnClose()`. |
| Trigger     | button. `disabled=false`; `nativeButton=true`; `id`; `payload`; `handle`.                                                                                                                                                          | Requires Root or handle. `aria-haspopup=dialog`; `aria-expanded` only for owning trigger; `aria-controls` follows actual popup ID. State `{disabled, open}` maps to `data-disabled`, `data-popup-open` (not popup's `data-open`). Multiple triggers preserve owner/payload when another trigger mounts.                                                                      |
| Portal      | div. `keepMounted=false`; `container` element/ShadowRoot/ref/null.                                                                                                                                                                 | Renders when mounted or kept. Provides portal context. Adds internal backdrop only while mounted and `modal===true`; internal backdrop becomes inert when closed.                                                                                                                                                                                                            |
| Backdrop    | div. `forceRender=false`.                                                                                                                                                                                                          | Presentation role, user-select disabled, hidden when unmounted. Suppressed when nested unless forced. State `{open, transitionStatus}` maps open/closed/starting/ending attributes.                                                                                                                                                                                          |
| Viewport    | div. No extra props.                                                                                                                                                                                                               | Requires Root and Portal. Presentation role; renders when mounted or portal kept; hidden when unmounted; pointer events disabled when closed. State `{open, nested, transitionStatus, nestedDialogOpen}`.                                                                                                                                                                    |
| Popup       | div. `initialFocus`; `finalFocus`.                                                                                                                                                                                                 | Requires Root and Portal. Role dialog, tab-focusable popup, generated/overridden popup ID, reactive labelledby/describedby. Same state as Viewport; `--nested-dialogs` contains count. Stops composite navigation key propagation. Focus manager active while mounted, restores focus to popup when focused content disappears.                                              |
| Title       | h2. Native props / explicit ID.                                                                                                                                                                                                    | Registers label ID, updates on change, unregisters on removal. Empty part-specific state.                                                                                                                                                                                                                                                                                    |
| Description | p. Native props / explicit ID.                                                                                                                                                                                                     | Registers description ID with the same lifecycle. Empty part-specific state.                                                                                                                                                                                                                                                                                                 |
| Close       | button. `disabled=false`; `nativeButton=true`.                                                                                                                                                                                     | When open, requests close with `close-press`; disabled suppresses. Popup default initial focus is first tabbable child, except touch opens focus the popup to avoid a virtual keyboard. `false` disables movement; `true` chooses defaults; ref chooses its element; callback receives mouse/touch/pen/keyboard and can return an element, true/null (default), false/undefined (none). Final focus has equivalent options, defaulting to trigger or previous element.

Change reasons are `trigger-press`, `outside-press`, `escape-key`, `close-press`, `focus-out`, `imperative-action`, `none`. [Store setOpen](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/dialog/store/DialogStore.ts) notifies consumer **before** internal dispatch/state update, then honors `isCanceled`. When closing it supplies previous owning trigger if absent.

Dismissal is topmost-only for nested dialogs, left-button/single-touch only, and modal presses must belong to its backdrop. With backdrop, intentional dismissal happens on click, not mousedown; v1.8.0 rejects the trailing click of a press begun before open. Nonmodal/trap-focus variants without backdrops have distinct sloppy/intentional paths. Test shadow DOM, touchend with remaining fingers, and independently rendered sibling dialogs. [Interaction logic](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/dialog/root/useDialogRoot.ts), [useDismiss](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/floating-ui-react/hooks/useDismiss.ts), [Dialog regressions](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/dialog/root/DialogRoot.test.tsx).

`createHandle<Payload>()` returns Handle with `open(triggerId|null)`, `openWithPayload(payload)`, `close()`, `isOpen`. Calls without mounted Root are ignored. Detached triggers register against an inert fallback and migrate on attach/detach; Root remount gets fresh defaults. Missing trigger ID opens unassociated with a development warning. A transient overlapping-root attachment restores the prior root when the newer one detaches. [Handle](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/dialog/store/DialogHandle.ts), [shared handle lifecycle](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/utils/popups/popupHandle.ts).

## Early Drawer acceptance gate

Drawer reuses Dialog root/overlay machinery; use it to expose gaps in that foundation before broad component work. Full exports include Backdrop, Close, Content, Description, Indent, IndentBackground, Popup, Portal, Provider, Root, SwipeArea, Title, Trigger, Viewport, VirtualKeyboardProvider, createHandle, Handle. [Namespace](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/drawer/index.parts.ts).

Minimum early probe:

1. Dialog control/cancel/portal/focus/presence tests pass when Root runs in Drawer mode. Drawer Popup defaults initial focus to popup, not first tabbable. Viewport ownership is required for expected operation.
2. `swipeDirection='down'`, `snapToSequentialPoints=false`; controlled `snapPoint`, initial default `defaultSnapPoint !== undefined ? defaultSnapPoint : (snapPoints?.[0] ?? null)` (explicit null preserved). Snap points accept viewport fractions, pixel numbers, px/rem strings. Invalid uncontrolled active values fall back to default.
3. Canceled close leaves drawer open and active snap unchanged. Canceled `onSnapPointChange` leaves snap unchanged. Closing normally resets snap to default. Swipes without resolved direction do not snap/dismiss; scrolling content, page scroller, nonprimary pointers, and swipe-ignore elements must not steal gestures.
4. Nested drawer count/height/swipe state updates before passive effects; nested Dialog/AlertDialog is not a nested Drawer. Swipe release/cancel cleans global listeners and styles. Android CloseWatcher is topmost-only and feature-detected.

Pinned evidence: [Root](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/drawer/root/DrawerRoot.tsx), [Root acceptance cases](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/drawer/root/DrawerRoot.test.tsx), [snap regressions](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/drawer/root/DrawerSnapPoints.test.tsx), [Popup acceptance cases](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/drawer/popup/DrawerPopup.test.tsx). This gate does not yet cover all Indent, keyboard geometry, swipe velocity/threshold, or CSS variable contracts.

## Early Toast acceptance gate

Exports: Provider, Viewport, Root, Content, Description, Title, Close, Action, Portal, Positioner, Arrow, useToastManager, createToastManager. [Namespace](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/toast/index.parts.ts).

Minimum early probe:

1. Provider defaults `timeout=5000`, `limit=3`; zero timeout persists. Manager offers reactive `toasts`, `add` (returns ID), `close(id?)` (all if omitted), `update(id, options|updater)`, `promise`. Existing ID upserts in place and refreshes timeout; custom data replaces wholesale. Promise tracks loading/success/error and preserves promise result/rejection.
2. Newest active toasts consume limit; oldest excess entries get `limited` and inert state, rather than immediate deletion. `onClose` runs on logical close; `onRemove` only after exit and physical removal. Unknown or ending-toast updates do nothing. Reactive provider limit recalculates flags.
3. Timers pause on viewport hover/focus, window blur, and active touch interaction; resume only when appropriate. Remaining active time accumulates across repeated pause cycles. A newly added/rescheduled toast while paused stays paused. Dispose clears timers/subscriptions.
4. Viewport is labelled Notifications, role region with polite live announcements; high priority produces alert announcement and alertdialog root, low priority dialog root. Label IDs track mounting/removal. F6 enters viewport; Tab and Shift+Tab preserve access/return focus. Escape only closes where intended.
5. Default swipe directions down/right; lock initial axis, reject nonprimary buttons, threshold-dependent close, cancel release cleanly, and do not swipe anchored Toasts. Root identity may be recreated: index/height metadata must follow ID, not object identity.

Pinned evidence: [Provider](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/toast/provider/ToastProvider.tsx), [manager contracts](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/toast/useToastManager.ts), [Store](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/toast/store.ts), [timer/store cases](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/toast/store.test.ts), [Viewport cases](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/toast/viewport/ToastViewport.test.tsx), [Root cases](https://github.com/mui/base-ui/blob/47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c/packages/react/src/toast/root/ToastRoot.test.tsx). Anchored positioning/arrow geometry and exhaustive CSS variables require a subsequent inventory.

## Implementation decisions still required

- Choose and document Svelte-native render snippet, DOM attachment/ref, state-dependent class/style, actions, and manager naming while keeping observable behavior. Do not silently promise React API syntax parity.
- Set a concrete minimum Svelte 5 version for SSR-stable ID support; verify against official Svelte documentation in implementation work.
- Implement overlays using native DOM semantics with tested shadow-root and nested portal focus behavior. The React-specific Floating UI focus/portal hooks cannot be directly copied as Svelte primitives.
- Bring upstream regression scenarios over as behavioral tests, with browser tests for focus, touch, animation, scroll lock, and hydrated markup. Static markup or compile success alone cannot establish parity.
- Keep the first milestone foundation + complete Dialog; use limited Drawer/Toast fixtures as acceptance probes. Mark all other components unsupported until their own public API/state/interaction inventory and tests exist.
