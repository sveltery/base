# Shared source utilities

The internal shared helpers under `packages/base/src/lib/utils` port the pinned Base UI v1.8.0 dependencies needed by Input/Field and rendering. They preserve initial controlled ownership/default fallback, uncontrolled setters, diagnostics, logger deduplication, timer cancellation/teardown and callback-before-previous-update tracking. Consumers initialize helpers during component setup and retain returned refs, callback trampolines and value readers.

Svelte supplies live state, setup identity and client effects. Controlled props and values use live accessors; stable callbacks receive closures reading live props and execute under `untrack`. React render guards, insertion commit state and implicit callable-default initialization are not imposed on native Svelte. Explicit effect dependency getters avoid incidental subscriptions while retaining cleanup; callback-only usage has native effect tracking.

The [source correspondence](../parity/shared-utils/source-correspondence.md), [complete hashed closure](../parity/shared-utils/source-graph.json) and [compatibility observations](../parity/shared-utils/compatibility.md) describe each boundary and its limits. [Executed checks](../parity/shared-utils/verification.md) include supplemental rendered DOM/SSR probes, which earn zero upstream assertion credit. Current main components are not automatically audited by these new helpers; each dependent component must use and review the canonical source closure. This work is internal and does not add public package exports or establish whole-library parity.
