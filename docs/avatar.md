# Avatar

Avatar ports the Root, Image and Fallback contract from Base UI 1.8.0 at immutable commit `47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c`. Runtime dependencies are the existing Element/mergeProps/class composition, private Avatar context and private animation completion. There is no Field, Form or overlay dependency. Public root/subpath exports await the serialized integration patch.

Root renders a span and exposes `imageLoadingStatus`. Image renders an img with empty default alt once its detached probe loads; `keepMounted` renders it immediately and derives status from the actual rendered host. Fallback renders a span until the image loads, optionally after `delay` milliseconds. All three accept native element props, state-dependent `class`/`style`, render/children snippets and bindable refs. The six named Props/State exports and `ImageLoadingStatus` mirror the source type surface through the accepted framework substitutions.

The default probe assigns handlers, referrer policy, cross origin, sizes, srcset and src in that order. Cached complete probes resolve by naturalWidth, missing sources report error, obsolete callbacks are ignored, and image disposal resets Root to idle. Loading callbacks precede Root status publication; idle is suppressed. Presence persists while an exiting image's animations finish, including canceled/replacement animations and cancellation when loading becomes visible again. The starting phase clears on a frame. Missing animation APIs and BASE_UI_ANIMATIONS_DISABLED complete immediately. Fallback has no exit animation; its timer belongs to the part, does not restart on source changes, and once passed never re-hides for a new delay.

With `keepMounted`, no detached probe is constructed. Loading/error attributes and aria-hidden belong only to this mode. Native load/error handlers run before the internal status update and can call preventBaseUIHandler; preventDefault alone does not suppress it. Initial already-complete images resolve before paint without a new enter phase. The server emits the image hidden from assistive technology and emits the fallback until hydration resolves status. Cached hydration and no-flash assertions require actual browser execution; SSR strings or mock completion alone do not establish them.

See [immutable assertion trace](../parity/avatar/README.md), [compatibility record](../parity/avatar/compatibility.md), and [verification](../parity/avatar/verification.md). Ordinary declarations, parameterization, conformance helpers, type assertions and supplemental cases are accounted separately. This implementation does not establish whole-library parity or complete native accessibility coverage.
