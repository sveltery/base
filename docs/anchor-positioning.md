# Private anchor positioning foundation

This milestone is internal infrastructure for future anchored components. No public Positioner, Menu, Popover, Tooltip or Select API is shipped. The `/anchor-positioning` development fixture demonstrates actual element and virtual anchors, live offsets, logical and DOM direction, clipping, resize/scroll updates, replacement, keepMounted reopening, arrow origins and native top/left output beside the installed Base UI React reference.

The geometry engine is Floating UI DOM 1.8.0 with its default platform. Native Svelte attachments register the actual reference/floating/arrow hosts; effects synchronize measurement and observer ownership. The pinned Base UI middleware policy remains authoritative, including its custom arrow offset-parent and all-zero-reference hiding rules. Fixed zero coordinates and opacity zero precede positioning. Property-level CSS writes preserve measured available-size variables through unrelated reactive updates.

[Source provenance and remaining scope](../parity/anchor-positioning/README.md), [compatibility choices](../parity/anchor-positioning/compatibility.md) and [verification](../parity/anchor-positioning/verification.md) describe this bounded implementation. Browser evidence and final review are pending. Context providers alone do not prove geometry; geometry alone does not implement popup interactions, accessibility, focus/portal ownership, touch scroll policy or dismissal. Existing public families remain incomplete as recorded in the catalog.
