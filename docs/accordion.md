```svelte
<script lang="ts">
  import { Accordion } from '@sveltery/base';
</script>
<Accordion.Root defaultValue={['details']}>
  <Accordion.Item value="details">
    <Accordion.Header><Accordion.Trigger>Details</Accordion.Trigger></Accordion.Header>
    <Accordion.Panel>Panel content</Accordion.Panel>
  </Accordion.Item>
</Accordion.Root>
```

Root renders a div and defaults to an empty value array, `multiple=false`, `disabled=false`, `keepMounted=false`, `hiddenUntilFound=false` and `orientation='vertical'`. `value` and `defaultValue` are arrays in both single and multiple mode. Treat state arrays as read-only. The initial controlled mode and default remain fixed for the component lifetime. A controlled change calls `onValueChange(nextValues, details)` and waits for the owner's update. Removing an initially controlled value falls back to the initial default while retaining controlled mode, matching the pinned useControlled helper.

Item renders a div, Header an h3, Trigger a button and Panel a div with `role='region'`. An Item without a value receives a generated ID value. Explicit values use reference identity, including objects. Root single mode compares the first selected value; multiple mode appends on opening and removes all strictly equal values on closing. Item callbacks run before Root callbacks and receive the same details object. Item cancellation prevents the Root callback; Root cancellation prevents the internal value write. Reasons are `trigger-press` and `none`. Cancellation preserves native event defaults and propagation unless the consumer cancels those separately.

Item disabled combines its own value with Root disabled. Trigger disabled combines its own value with Item disabled: `disabled=false` cannot enable a Trigger inside a disabled Item or Root. This differs from Collapsible's explicit Trigger override. Disabled native Triggers remain focusable with aria-disabled and suppress activation. Native `type`, `form`, `name` and `value` retain button behavior. Custom hosts use `nativeButton=false` and the existing Button keyboard/event contract. Enter and Space activate supported native/custom Triggers. Deprecated `orientation` and `loopFocus` remain accepted; orientation remains observable state and a data attribute, but neither prop implements roving focus or Arrow/Home/End navigation. Items register their index in DOM order, including reordering and removal.

Trigger's ID labels its Panel through `aria-labelledby`; an open Trigger uses `aria-controls` for the Panel ID. Closed Triggers omit that relationship even when the Panel is retained. Explicit ID updates, removal and remount follow registration ownership. Panel props override Root `keepMounted` and `hiddenUntilFound` defaults. Effective hiddenUntilFound keeps a closed Panel mounted; SSR emits the pinned boolean hidden attribute and the attached client host uses `hidden='until-found'`. It overrides keepMounted and retains the source warning for an explicit false combination. Accepted beforematch opening skips entrance animation for that request; cancellation leaves the next ordinary opening animated.

Panel exposes measured `--accordion-panel-height` and `--accordion-panel-width`, open/closed and starting/ending attributes, and transition status `starting`, `idle`, `ending` or undefined. Initial-open keyframes are suppressed; subsequent motion uses authored CSS and measured dimensions. Completion, replacement, reopening and teardown use the inherited bounded Collapsible lifecycle. Root state contains value/disabled/orientation; Item adds open/hidden/index, and Header/Trigger use that Item state. Their public state has no transitionStatus. The inherited no-motion close quirk can retain Panel `idle` ([#33](https://github.com/sveltery/base/issues/33)). Collapsible's removed-host `ending` quirk ([#34](https://github.com/sveltery/base/issues/34)) concerns the private lifecycle here; its public Root/Trigger transition claims do not transfer to Accordion.

Composition uses the accepted five framework substitutions: class, CSS strings, children/render snippets, bindings/attachments and native events. Replacement snippets must spread supplied props, including attachment symbols. The initially undefined ref contract follows [A-01](upstream-differences.md#a-01-approved-proposed-core-audit-repairs-and-substitutions). Named props/state/change-detail exports represent React namespace types. `AccordionValue<T=any>`, `AccordionRootProps<T=any>` and `AccordionRootState<T=any>` retain upstream generic inference and its permissive default; explicit generics constrain values and callback arrays. No actions or completion callback API is introduced.

The unchanged Button helper inherits [D-03](upstream-differences.md#d-03-disabled-chorded-mousedown-default-focus), without new parity credit. The shared Panel hook also preserves Collapsible's value-only alignment restoration losing authored !important priority ([#30](https://github.com/sveltery/base/issues/30)) and beforematch listener ownership of the original rendered host ([#31](https://github.com/sveltery/base/issues/31)). Existing Collapsible reproducers are evidence for those shared sources; Accordion-specific execution must be recorded separately. Corrections and React.Activity scope remain deferred. Read [compatibility](../parity/accordion/compatibility.md) and [verification](../parity/accordion/verification.md) for evidence and remaining gates; complete Accordion parity is not claimed.
