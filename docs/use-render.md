# UseRender composition

`UseRender` is a native Svelte 5 component adaptation of Base UI 1.8.0's public `useRender` hook, at immutable commit `47b40521eab921c2756bf9bdb0b0f07fbfdb8c8c`. It renders an intrinsic element or replacement snippet. Import it from `@sveltery/base` or `@sveltery/base/use-render`. This is a [delegated PM design decision](https://github.com/sveltery/base/pull/40#pullrequestreview-5396533264); explicit user acceptance of this additional component/name/return substitution is not recorded. The seven upstream ReactElement/null return assertions remain divergent and unported, with zero unchanged type credit.

The public parameters are `defaultTagName` (default `div`), `enabled` (default true), `state`, `stateAttributesMapping`, ordinary-object `props`, replacement `render`, separate `ref` and optional `bind:element`, and `children`. HTML and SVG hosts are supported. State values become lowercase `data-*` names: true produces an empty attribute, false and other falsy values disappear, and truthy values stringify. A custom map replaces that property's default mapping, even when it returns null. Explicit props override state attributes.

Replacement snippets receive merged symbol-bearing props, the current state and children. They must spread the supplied props onto their actual host so consumer and component attachments reach that element. To compose replacement-owned props last, use `mergeProps(suppliedProps, ownedProps)`; the first input retains enumerable attachment symbols. String CSS can be composed with `${suppliedProps.style ?? ''};font-size:16px`. References remain separate from prop merging. A replacement-owned ref uses its own attachment. Native `preventDefault()` does not suppress Base UI handlers; `preventBaseUIHandler()` does.

The private closure alone accepts ordered objects/getters and state-dependent class/style callbacks. Getters receive the accumulated props and replace them; they own callback chaining. These internal options are not added to the public hook's ordinary `props` object contract. The public component, private call shape and legacy Dialog Element now delegate to one [source-derived common renderer](../parity/use-render/source-correspondence.md). Legacy callers retain a visibly temporary state-attribute adapter while their component-specific mapping audits remain incomplete.

`ref` accepts callback/object refs or an array of them. Callback cleanup functions run on detach; callbacks without cleanup receive null. Object refs publish the actual host and clear on detach. Individual ref identities control attachment memoization. Native attachments own cleanup timing; class-only updates retain the existing refs. `bind:element` starts undefined unless initialized by its owner, publishes the host after attachment, and becomes null after removal, following the existing A-01 lifecycle. SVG, replacement-host swaps, ref-shape changes and teardown use the same ownership boundary.

Native attachments clean removed hosts after removal and clean replaced refs after same-host attribute updates. Cleanup therefore sees a disconnected host on removal or the new attributes on ref replacement. A cleanup that restores an earlier class can overwrite a just-authored class. Changed snippet identity can replace a same-tag native host; stable snippet identity with reactive arguments retains it. These actual Svelte observations follow the user's updated native-default direction and receive zero unchanged React assertion credit. Earlier scoped PM decisions are retained as [versioned compatibility history](../parity/use-render/compatibility.md); the current renderer does not force React ref commit timing.

An empty class string remains an empty value in source prop merging. Svelte emits `class=""` during SSR and omits that attribute during native hydration/client updates. The renderer preserves those native defaults without an attribute-fixing attachment. The common input branch uses a literal native `<input>` so Svelte owns input defaults, spread and hydration; it adds no value tracking, replay or reset logic.

When `enabled` is false, no state mapping, getter, class/style callback, replacement snippet or new ref work runs; an existing host still tears down. Only a default intrinsic button receives `type="button"`, and only a default intrinsic image receives `alt=""`; explicitly supplied props override defaults. Replacement snippets own their defaults.

The [dedicated assertion record](../parity/use-render/README.md) separates public declarations, internal closure declarations, return types, and supplements. React lazy/Suspense, Flight/RSC wrappers and React diagnostics are unimplemented; no Svelte equivalents or parity credit are invented. Proposed [PR #40](https://github.com/sveltery/base/pull/40) anchors the delegated PM public design review. `UseRenderParameters<State, Host, Enabled>` preserves parameter relationships, and `UseRenderComponentProps<Tag, State, RenderFunctionProps>` preserves the custom render-function-props generic. Type-only `UseRender.Props`, `.Parameters`, `.State`, `.RenderProp`, `.ElementProps` and `.ComponentProps` aliases are available; no React return alias is exported. Public root and `@sveltery/base/use-render` expose the component and 11 named UseRender type aliases plus the canonical `HTMLProps` and `ComponentRenderFn` types. Installed tarball checks verify entry identity, private export exclusion, SSR, DOM refs/updates/cleanup, types and MIT notices; they add no ordinary assertion credit. No package publication or production-readiness claim is made.
